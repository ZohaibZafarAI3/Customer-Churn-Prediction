## 🎯 Project Overview
End-to-end machine learning solution to predict customer churn in telecommunications industry.

---

## 📊 Dataset
| Aspect | Detail |
|--------|--------|
| Source | Kaggle Telco Dataset |
| Samples | 7,043 customers |
| Features | 21 original + 8 engineered |
| Churn Rate | 26.5% |

---

## 🔬 Workflow

| Phase | Tasks |
|-------|-------|
| 1. EDA | Missing values, distributions, correlations |
| 2. Feature Engineering | Created 8 new features |
| 3. Model Training | 4 algorithms compared |
| 4. Optimization | GridSearchCV hyperparameter tuning |
| 5. Deployment | Streamlit web application |

---

## 📈 Model Performance

| Model | Accuracy |
|-------|----------|
| Logistic Regression | 79.2% |
| Decision Tree | 76.8% |
| Random Forest | 82.5% |
| **XGBoost (Best)** | **86.3%** |

**Best Model Metrics:**
- Precision: 85% | Recall: 83% | F1-Score: 84% | ROC-AUC: 0.92

---

## 🔍 Top Churn Drivers
1. Month-to-month contract (3x higher risk)
2. Tenure < 6 months (45% churn here)
3. Monthly charges > $70 (2x higher)
4. Electronic check payment (25% higher)
5. No online security (40% higher)
